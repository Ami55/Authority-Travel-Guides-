# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/506af982-4aa7-47af-9534-a9a5601c7ad5

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app (guide generation uses the shared Bold Studio Gemini proxy; this app does not need its own API key):
   `npm run dev`
